# L.A. Cetto · Concepto de rediseño

Prototipo navegable del concepto de rediseño de lacetto.mx: portada, tienda, ficha de producto, colección premiada, experiencias, regalos, club, nuestra historia, trayectoria, cuenta y pago.

Es un sitio estático (HTML, CSS y JavaScript, sin compilación). El carrito, la cuenta y las reservas se guardan en el navegador para que el recorrido se sienta real; no hay pagos ni datos reales.

Para verlo en local, sirve la carpeta con cualquier servidor estático y abre `index.html`.
